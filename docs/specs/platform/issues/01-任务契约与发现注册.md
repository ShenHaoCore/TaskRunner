# 01 把任务契约与发现注册钉进 Core 缝

- 状态：`done`（2026-10-26；23 单元测试全绿，0 警告）
- Blocked by：无
- 缝：Core 公开服务（任务目录与仓储，开发规格确认的副缝）

## 交付什么

平台「任务即插件」能力的契约钉板：扫描发现规则、稳定 JobId、Cron 守卫、
运维覆盖的持久化语义、执行器行为、分层边界。对应开发规格 User Stories 1–4、16 与
Implementation Decisions 的任务契约/发现与注册两节。

## 现状（已随 v3.0.0 交付）

- 契约：单方法异步执行接口 + 特性标注默认 Cron / 名称 / 描述 / 启用；互斥与进度上报为可选标注。
- 启动期扫描宿主与额外程序集；未标注默认 Cron 的类型与抽象类型不注册；Core 无内置任务。
- JobId 生成：显式 Id 优先，否则去 `Job` 后缀转 kebab-case；任务类型名 = 全名 + 程序集简单名。
- 仓储 Sync：保留运维改过的 Cron 与启用标志；默认值翻回启用时恢复孤儿配置；RemoveMissing 清孤儿。
- Cron 守卫：接受 5/6 字段与 `@daily` 简写，拒绝 4/7 字段、空串与乱写。
- 执行器：成功记录日志，失败记录后原样重抛（交给 Hangfire 重试策略）。

## 验收条件

- [x] 扫描：未标注与抽象类型被忽略；Core 程序集扫描结果为零内置任务
- [x] JobId：显式 Id 直接采用；隐式生成去 `Job` 后缀、kebab-case
- [x] 任务类型名：全名 + 程序集简单名，跨程序集同名任务不冲突
- [x] Cron 守卫：5/6 字段与 `@daily` 接受；4/7 字段、空串、非 Cron 串拒绝
- [x] 仓储：Sync 保留运维覆盖值；默认由禁用变启用时重建孤儿配置；移除任务清孤儿配置
- [x] 执行器：成功与失败路径日志行为被钉住，失败重抛不被吞
- [x] 边界：Core 程序集/工程均不引用 Hangfire；Api 不引用 Worker（架构守护测试）
