## 目录约定

```
docs/
├── branch-management.md             ← 分支与发布流程
└── specs/
    ├── README.md                    ← 本索引
    └── platform/
        ├── spec.md                  ← 七段：问题 / 方案 / 用户故事 / 实现决策 / 测试决策 / 范围外 / 备注
        └── issues/
            ├── 01-<中文主题>.md     ← 标题 / 状态 / Blocked by / 缝 / 验收复选框 / 范围外
            └── ...
```

- **票的数字前缀只表顺序**，不代表依赖（依赖写在票的 `Blocked by`）。
- **票的状态**写在票头：`ready-for-agent` / `in-progress` / `done`；完成后勾满验收框并把状态改成 `done`。
- **新增特性**：先写规格（确认测试缝之后再切票），再在本索引"特性一览"里加一行。
- 文内链接一律相对路径。
