# 05 任务多队列

- 状态：`done`（2026-10-27）
- Blocked by：无（契约/注册可先钉 Core；REST 清单字段依赖主缝）
- 缝：Core 公开服务（队列标注与发现）+ REST `/api/tasks`（清单可见队列）+ Worker 订阅队列配置

## 交付什么

让周期任务可声明目标队列，Worker 按配置订阅一组队列，实现轻重任务隔离或简单优先级分流。
对应开发规格 User Stories 17–18。

## 现状

- Worker / Combined 固定 `Queues = ["default"]`；入队与周期注册均走默认队列。
- 契约特性无队列字段；清单视图不暴露队列名。

## 验收条件

- [x] 契约：可选队列标注；省略则等价 `default`；非法名（非小写字母/数字/`_`/`-`）在扫描期 fail-fast
- [x] 发现：描述符与落库/清单视图带上生效队列名（只读，不支持运维覆盖改队列——改队列需改代码重启）
- [x] 注册：周期作业与立即触发均入该任务声明的队列
- [x] 配置：`Hangfire:Queues`（字符串数组）决定 Server 订阅列表；缺省 `["default"]`；文档写明未订阅队列会积压
- [x] 部署说明：生产 Worker 未订阅某队列时，该队列作业会积压——README / 部署文档有一句警告
- [x] 测试：队列名守卫 + 扫描捕获 Queue；REST 清单含 `queue`；记录式调度器观察入队队列

- 延时/定时触发（票 06）。
