# 06 定时一次触发（未来绝对时刻）

- 状态：`done`（2026-10-27）
- Blocked by：无（可与票 05 并行；若 05 已合并则定时入队须带任务队列）
- 缝：REST `/api/tasks` 触发面 + `ITaskScheduler` 可观察调度行为

## 交付什么

运维可指定**未来某个绝对时刻**让已有周期任务**再跑一次**（非改 Cron）。
相对延时（「再过 N 秒」）作为同一接口的便捷写法，语义等价于换算成绝对时刻。
对应开发规格 User Story 19。

## 现状

- `POST /api/tasks/{jobId}/trigger` 仅立即 `Enqueue`；无 Schedule / 绝对时间参数。
- `ITaskScheduler` 只有 `Enqueue`，无延时/定时入口。

## 验收条件

- [x] 调度：可按 `DateTimeOffset` 登记一次 Scheduled 作业；到点入队执行同一 `jobType`
- [x] REST：触发接口支持「立即」与「定时」；body 接受 `runAt`
- [x] 便捷：可选 `delaySeconds`（正整数）；与 `runAt` 同时出现时拒绝 400
- [x] 校验：`runAt` 已过去 → 400 + message；任务不存在 → 404
- [x] 鉴权/只读：与现有 trigger 相同（写操作；只读模式拦截）
- [x] 响应：`queueJobId` + `scheduled: true`
- [x] 测试：定时触发有调度器证据；过去时间与双参数 400

## 不在本票范围

- 改写成新的周期任务；取消/改期已登记的 Scheduled（可用 Dashboard 原生删作业，本票不新开 REST）。
- Continuations / Batch（Pro）；多队列声明本身（票 05）。
