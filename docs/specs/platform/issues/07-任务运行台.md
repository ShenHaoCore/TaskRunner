# 07 任务运行台（搜 + 一键运行）

- 状态：`done`（2026-10-27）
- Blocked by：无（复用现有清单与立即触发；票 06 合并后可再挂定时，本票不阻塞）

## 交付什么

任务多时不必抄 JobId 或钻 Dashboard：登录后一页列出平台任务，可按名称/JobId 过滤，一键立即运行。
对应开发规格 User Story 20。

## 现状

- 触发能力已有：`POST /api/tasks/{jobId}/trigger`；清单：`GET /api/tasks`。
- `login.html` 可发会话 Cookie；首页只链到 API JSON / Dashboard，无「搜任务 → 运行」页。
